# Code Review Report

Generated by Codex adversarial review — 2026-05-05

## Findings

### [HIGH] Deleted-account check bypassed by fast-path cookie — FIXED
**File:** `src/middleware.ts`

When `pp_onboarded=1` cookie was present, middleware skipped the entire profile DB query, including the `deleted_at` check. A soft-deleted user retaining the one-year cookie could continue accessing all protected pages indefinitely.

**Fix applied:** Fast-path cookie still skips the `onboarding_completed` query but now always performs a lightweight `SELECT deleted_at` query. Deleted accounts are signed out and redirected regardless of cookie state.

---

### [MEDIUM] Bots endpoint returned all coins without location filtering — FIXED
**File:** `src/app/api/bots/route.ts`

The GET handler parsed `lat`/`lng` parameters but didn't use them in the Supabase query — every `admin_coins` row was returned to every authenticated caller. This exposed full placement data and would degrade performance as the coin table grows.

**Fix applied:** Added a ~10 km bounding box filter (`±0.09°` on both axes) and a `LIMIT 50` cap. Only coins near the caller's location are returned.

---

### [INFO] `admin_coins` table must be created in Supabase — PENDING (requires manual migration)
The API routes and types reference an `admin_coins` table that does not yet exist in the database. GET `/api/admin/coins` returns 500 until the table and RLS policies are created.

**Required SQL (run in Supabase SQL editor):**
```sql
create table if not exists admin_coins (
  id uuid primary key default gen_random_uuid(),
  lat double precision not null,
  lng double precision not null,
  created_by uuid references profiles(id) on delete set null,
  created_at timestamptz not null default now()
);

alter table admin_coins enable row level security;

create policy "admin_coins_admin_all"
  on admin_coins
  for all
  using (
    exists (
      select 1 from profile_roles pr
      join roles r on r.id = pr.role_id
      where pr.user_id = auth.uid() and r.name = 'admin'
    )
  );
```
